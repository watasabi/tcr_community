# Relatórios Descritivos

Este diretório contém tabelas descritivas geradas a partir da base de pacientes.

## Arquivos incluídos

- `demo_faixa_etaria.csv` — distribuição de faixa etária
- `demo_genero.csv` — distribuição por gênero
- `demo_local_residencia.csv` — distribuição por local de residência
- `clin_escala_apache_ii.csv` — resumo numérico da escala APACHE II
- `clin_tempo_internacao_uti.csv` — resumo numérico do tempo de internação na UTI
- `clin_desfecho_clinico.csv` — frequência de desfecho clínico bruto
- `clin_desfecho_padronizado.csv` — frequência de desfecho clínico padronizado
- `clin_diagnostico_principal.csv` — frequência de diagnóstico principal
- `clin_comorbidades.csv` — frequência de comorbidades
- `clin_ventilacao_mecanica.csv` — frequência de ventilação mecânica
- `clin_drogas_vasoativas.csv` — frequência de uso de drogas vasoativas
- `clin_hemodialise.csv` — frequência de hemodiálise
- `clin_procedimento_cirurgico.csv` — frequência de procedimentos cirúrgicos
- `clin_transfusao_sanguinea.csv` — frequência de transfusão sanguínea
- `clin_cuidados_paliativos.csv` — frequência de cuidados paliativos
- `clin_parada_cardiorrespiratoria.csv` — frequência de parada cardiorrespiratória
- `clin_dispositivo_invasivo.csv` — frequência de uso de dispositivos invasivos
- `clin_feridas_lpp.csv` — frequência de feridas LPP
- `clin_vicios.csv` — frequência de vícios
- `clin_procedencia.csv` — frequência de procedência de entrada no serviço
- `clin_causa_obito.csv` — frequência de causa de óbito
- `clin_uti.csv` — frequência de UTI

## Como interpretar

- Cada CSV contém `valor`, `absoluta` e `relativa`.
- A `relativa` é a proporção de cada categoria dentro da amostra disponível.
- Para variáveis numéricas, os arquivos contêm valores de `n`, `media`, `mediana`, `min`, `max` e `desvio_padrao`.
