PLANO DE DESENVOLVIMENTO & ORÇAMENTO
Proposta de Análise de Dados e Modelagem Estatística
Esta proposta tem como objetivo estruturar a análise de dados do projeto de pesquisa, indo
além da estatística tradicional. A abordagem proposta utiliza técnicas de Ciência de Dados e
Estatística Multivariada para extrair o máximo de valor dos dados coletados, identificando
padrões complexos e perfis ocultos de pacientes.
Fase 1: Análise Estatística Descritiva e Inferencial (Escopo Base)
Esta fase garante o cumprimento de todos os requisitos metodológicos aprovados no projeto
de pesquisa, entregando as métricas e testes exatos necessários para a caracterização inicial.
●​ Estatística Descritiva: Elaboração de tabelas de frequência absoluta e relativa para todas
as variáveis categóricas (ex: Gênero, IRAS, Desfecho clínico).
●​ Medidas de Tendência e Dispersão: Cálculo rigoroso de média, mediana, valores
mínimos/máximos e desvio padrão para as variáveis quantitativas (ex: Escala APACHE II,
Tempo de internação e Faixa Etária).
●​ Testes de Associação Bi-variada: Aplicação de testes estatísticos (como o teste
Qui-quadrado de Pearson ou Exato de Fisher) para validar estatisticamente as hipóteses
do estudo, como a relação direta entre variáveis clínicas (ex: presença de comorbidades) e
o desfecho clínico (alta/óbito).
Fase 2: Estatística Multivariada e Detecção de Perfis (Aprofundamento)
Nesta etapa, aplicaremos algoritmos de Machine Learning para identificar grupos (clusters)
sociodemográficos e clínicos, elevando o nível de profundidade da pesquisa.
●​ Algoritmo K-Prototypes: Utilização de técnica avançada de clusterização desenhada
especificamente para bases de dados mistas. Isso permitirá agrupar os pacientes
avaliando simultaneamente variáveis numéricas (como o escore APACHE II) e variáveis
categóricas (como uso de ventilação mecânica ou drogas vasoativas).
●​ Análise de Correspondência Múltipla (MCA), Clusterização Hierárquica &
Clusterização clássica: Redução da dimensionalidade das variáveis categóricas para
criação de dendrogramas. Esta técnica visual demonstrará graficamente como os perfis
dos pacientes se distanciam ou se aproximam (ex: isolando um perfil de idosos crônicos
em cuidados paliativos versus um perfil de pacientes agudos cirúrgicos).●​ Árvores de Decisão (Decision Trees): Modelagem explicativa focada em entender o
peso de cada variável no desfecho clínico. A árvore mapeará quais combinações de regras
e características (ex: "Se APACHE > X" e "Transfusão = Sim") apresentam maior
probabilidade de levar ao óbito.
Alinhamento de Expectativas: O Risco Analítico
É fundamental deixar explícito que a formação de "perfis" bem definidos (clusters) depende
intrinsecamente da variância existente nos dados coletados. Se a amostra for excessivamente
homogênea (por exemplo, se a esmagadora maioria dos pacientes apresentar características
sociodemográficas e de gravidade muito idênticas), os algoritmos podem não encontrar
grupos estatisticamente separados. A análise apontará o que os dados mostram, garantindo o
rigor científico em qualquer cenário.
Acompanhamento e Suporte Contínuo
O serviço inclui acompanhamento direto durante a fase de redação dos resultados. Caso a
pesquisa demande gráficos adicionais, cruzamentos específicos de variáveis ou testes
complementares não previstos inicialmente para refinar a discussão, essas solicitações estão
cobertas pelo escopo.

Proposta Comercial e Orçamento
O investimento proposto cobre desde o tratamento inicial da base de dados até o suporte final
para a confecção do texto, contemplando técnicas analíticas além do escopo de um serviço de
estatística tradicional.
